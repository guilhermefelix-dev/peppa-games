Sobre o projeto

O Peppa Games é um projeto desenvolvido pela Equipe Peppa com o objetivo de criar um catálogo de jogos. O site reúne informações sobre diferentes títulos,
apresentando jogos de diversos gêneros e estilos para facilitar a busca e a descoberta de novos jogos pelos usuários.

Além de conhecer novos jogos, os usuários poderão compartilhar seus conhecimentos,
dicas e macetes para ajudar outras pessoas que estejam enfrentando dificuldades em determinadas partes ou desafios dos jogos.
Dessa forma, o Peppa Games busca criar um espaço onde os jogadores possam encontrar informações e também contribuir com a comunidade.
